# 🚀 SecLab Presence

Uma ferramenta de Rich Presence para Discord que permite exibir atividades personalizadas no perfil, sem a necessidade de estar realmente executando a atividade mostrada.

## ✨ Recursos

* 🎮 Atividades personalizadas
* 🖼️ Suporte a imagens de Rich Presence
* ⚡ Configuração rápida e simples

## 📦 Instalação

```bash
git clone https://github.com/draxz-official/SecLab-Presence.zip
cd SecLab-Presence
```

## 🚀 Como usar

Visite o arquivo LEIA-ME.txt

## ⚠️ Aviso

Este projeto utiliza a API de Rich Presence do Discord. O uso da ferramenta é de responsabilidade do usuário.
